Account Switcher

A fast, lightweight Windows utility built to seamlessly switch between multiple gaming accounts with a single click, no manual logins required

Features
- Instant switching for Steam and Riot Games accounts
- Modern dark luxury UI designed for minimal system impact
- Fast and secure handoff utilizing local client sessions
- Portable, single-file executable with zero runtime dependencies

Built With
- C# / .NET 8
- WPF (Windows Presentation Foundation)
